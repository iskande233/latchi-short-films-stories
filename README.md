# LATCHI Short Films Stories

مستودع منظم لإنشاء أفلام قصيرة دقيقة واحدة باستعمال أدوات الذكاء الاصطناعي.

## الهدف
هذا المستودع يحتوي على كل ما يحتاجه أي وكيل/محرر فيديو لإنشاء الفيديو النهائي:

- صور الشخصيات المرجعية.
- صور كل مشهد بالترتيب.
- حوار كل لقطة بالدارجة الجزائرية.
- ترجمة عربية فصحى وإنجليزية.
- Prompt الصورة لكل مشهد.
- Prompt تحريك الصورة إلى فيديو لكل مشهد.
- ملف SRT للترجمة.
- تعليمات مونتاج وإخراج.

## الأفلام الموجودة

### 001 - المرأة اللي رجعت
المسار:

```text
films/001_al_maraa_elli_rjaat/
```

قصة: شاب يساعد عجوز في الطريق، وفي الأخير يكتشف أنها أمه التي ضاعت منه وهو صغير.

## طريقة العمل المقترحة

1. افتح مجلد الفيلم.
2. استعمل صور `assets/references` كمرجع ثابت للشخصيات.
3. استعمل صور `assets/scenes` بالترتيب.
4. استعمل ملف `docs/production_brief.md` كتعليمات كاملة للوكيل.
5. حرّك كل صورة باستعمال Prompt الفيديو الخاص بها.
6. ركب اللقطات حسب التوقيت.
7. أضف Voice Over بالدراجة الجزائرية.
8. أضف الترجمة من `subtitles/`.
9. صدّر الفيديو النهائي 9:16 لمدة 60 ثانية.

## إعدادات عامة لكل فيديو

- Format: Vertical 9:16
- Duration: 60 seconds
- Style: realistic cinematic emotional drama
- Language: Algerian dialect
- Subtitles: Arabic + optional English
- Music: emotional piano, soft strings

## ملاحظة مهمة
للحفاظ على نفس الوجوه، يجب استعمال صور الشخصيات المرجعية في كل أدوات الفيديو التي تدعم Character Reference / Image Reference.
