# 🕷️ القاعدة الذهبية — الهوية السرية (مثل الفيلم الحقيقي)

> ⚠️ **هذي القاعدة إلزامية في كل المشاهد** — بدونها ما يكونش الفيلم واقعي.

---

## 📌 القاعدة:

### 1️⃣ أنيس = شخص عادي 100%
```
عندما يظهر أنيس في مشهد (تاكسي، سوق، شارع، بيت):
- يلبس ملابسه العادية (تيشيرت + جينز أو قميص عادي)
- بدون قناع، بدون بدلة، بدون أي شيء يلمّح لهويته
- لا أحد يعرف أنه سبايدرمان
```

### 2️⃣ سبايدرمان = بدلة كاملة + قناع مغلق
```
عندما يظهر سبايدرمان في مشهد (بطولة، مطاردة، إصلاح):
- البدلة الحمراء والزرقاء كاملة من الرأس للقدمين
- القناع يغطي الوجه بالكامل — العيون البيضاء الكبيرة فقط
- الوجه لا يظهر أبداً — لا يمكن التعرف عليه
```

### 3️⃣ التحول (تغيير الملابس) = مشهد خاص
```
عندما يريد أنيس التحول لسبايدرمان:
- يذهب لمكان منعزل (زنقة، سطح، حمام عمومي، كوة بناء)
- يخرج الحقيبة/الكيس — يجبد البدلة منو
- يلبس البدلة بسرعة ويغطي وجهه بالقناع
- بعدها يخرج للقيام بالبطولة
```

## 🧑🎨 الشخصيتان (منفصلتان — تحديث الوصف)

```
Photorealistic young Algerian man, Anis, 25 years old, 178 cm tall, slim athletic
build, short black wavy hair, thin dark eyebrows, expressive dark brown eyes,
```

```
Photorealistic full-body superhero: Spider-Man wearing the classic complete
red-and-blue suit with black web pattern covering his ENTIRE body from head to
toe. The mask covers his whole face completely — only the large white expressive
eyes are visible. NO part of his face, hair or skin is ever visible. Slim
athletic build. Same suit design in every scene, identity always hidden.
```

## 🎬 المشاهد الجديدة المطلوبة (التاكسي + التحول + الهجوم)

### 🚖 المشهد: التاكسي (أنيس عادي تماماً)
| العنصر | التفاصيل |
|---|---|
| **الشخصيات** | أنيس (ملابس عادية) + سي الطاهر (سائق التاكسي) |
| **الحدث** | أنيس يركب التاكسي مثل أي شخص عادي — يتحدث مع السائق |
| **الكلام** | سي الطاهر: "وين رايح يا ولدي؟" / أنيس: "للأب واب، خويا." |
| **مهم** | أنيس **بدون** أي شيء يلمّح — مجرد شب عادي |

### 🎒 المشهد: التحول (يجبد البدلة من الحقيبة)
| العنصر | التفاصيل |
|---|---|
| **الشخصيات** | أنيس (ملابس عادية) + حقيبة رياضية |
| **الحدث** | في زنقة خالية / سطح — يفتح الحقيبة، يجبد البدلة الحمراء والزرقاء، يلبسها بسرعة، يغطي وجهه بالقناع |
| **الكلام** | أنيس (لنفسه): "يا الله، نبداو الخدمة." |
| **مهم** | نرى لحظة التحول: من ملابس عادية → بدلة كاملة |

### 💥 المشهد: الهجوم على الأشرار (بعد التحول)
| العنصر | التفاصيل |
|---|---|
| **الشخصيات** | سبايدرمان (بدلة كاملة) + الأشرار |
| **الحدث** | سبايدرمان يقفز ويوقف الأشرار — الناس ما يعرفوش مين هو |
| **الكلام** | سبايدرمان: "ها هو سبايدرمان! وخا ما تكونوش عارفين وجهي." |
| **مهم** | الوجه مخفي تماماً — لا أحد يعرف أنه أنيس |

## ✅ قائمة التحقق لكل مشهد

- [ ] إذا ظهر **أنيس** → ملابس عادية، بدون قناع/بدلة
- [ ] إذا ظهر **سبايدرمان** → بدلة كاملة، وجه مخفي
- [ ] إذا في **تحول** → مشهد خاص: حقيبة + يجبد البدلة + يلبسها
- [ ] لا أحد في القصة يعرف هوية أنيس
- [ ] الناس تشوف "سبايدرمان" ماشي "أنيس"
