# 🕷️ سوبر ذزيري — مذكرة إعادة بناء الصور المرجعية للشخصيات
## Arena / Seedance 2.5

> الهدف: تثبيت تصميم سينمائي خيالي ثابت للشخصيات البشرية، ثم إعادة إنشاء صور المشاهد اعتمادًا على هذه المراجع. لا نعيد توليد الشخصيات المقنّعة الجيدة.

---

## 1. القاعدة الأساسية

نريد شخصيات **خيالية أصلية** تبدو واقعية مثل فيلم جزائري Live-Action، وليست نسخًا أو إعادة إنشاء لأشخاص حقيقيين.

**Character Reference = الشكل**
**Scene Image = الوضعية + المكان + الكاميرا**
**Video Prompt = الحركة + الحوار + الصوت + الانتقال**

لا نعتمد على وصف وجه طويل داخل كل Video Prompt.

لا تستخدم:
- اسم شخص حقيقي أو شخصية عامة.
- قياسات دقيقة جدًا للوجه والجسم.
- عبارات إعادة إنشاء هوية شخص حقيقي.
- celebrity likeness / real-person recreation.

---

# 2. التصميم السينمائي الثابت — ANIS

شخصية جزائرية خيالية شابة بالغة، مظهر يومي عادي، غير مبنية على أي شخص حقيقي.

- شعر أسود قصير متموج قليلًا.
- عينان داكنتان.
- لحية خفيفة طبيعية.
- بشرة زيتونية متوسطة.
- جسم طبيعي رشيق.
- ملامح عادية غير مبالغ فيها.

### الملابس
- T-shirt رمادي فاتح.
- Jeans أزرق.
- حذاء رياضي داكن.
- حقيبة كتف صغيرة داكنة عند الحاجة.

**ثبات الشخصية:** نفس الشعر، اللحية، لون البشرة، العمر الظاهر، البنية العامة والملابس في نفس الفترة الزمنية.

---

# 3. التصميم السينمائي الثابت — ZAHRA

امرأة جزائرية مسنة خيالية، مظهر طبيعي وودود، غير مبنية على شخص حقيقي.

- علامات عمر طبيعية.
- شعر رمادي/داكن بحسب المرجع.
- ملامح شعبية جزائرية عادية.
- لباس جزائري شعبي بسيط.
- حقيبة يد بسيطة.

نفس الوجه والعمر واللباس الأساسي في جميع المشاهد.

---

# 4. التصميم السينمائي الثابت — SI TAHAR

رجل جزائري خيالي في منتصف العمر، سائق تاكسي، مظهر عادي وغير مشهور.

- شعر داكن مع شيب طبيعي.
- ملامح واقعية عادية.
- جسم متوسط.
- لباس يومي عملي.

نفس الوجه والشعر والعمر والملابس في مشاهد التاكسي.

---

# 5. التصميم السينمائي الثابت — THIEF

شاب جزائري بالغ خيالي، رشيق ومناسب للجري.

- شعر قصير داكن.

# 6. التصميم السينمائي الثابت — KOUIDER

رجل جزائري بالغ خيالي، مظهر واقعي عادي، مناسب لدوره في الحومة/الشرطة.

# 21. قاعدة Seedance بعد الصور

### صورة واحدة
ارفع الصورة كـ:
`PRIMARY REFERENCE / START FRAME`

### صورتان
ارفع:
`IMAGE 1 = START FRAME`
`IMAGE 2 = END FRAME`

ثم:

```text
The first uploaded image defines the exact starting visual state.
The second uploaded image defines the exact ending visual state.
Create one continuous physical action connecting the two states.
Do not redesign the fictional character.
Preserve the established cinematic character design.
```

---

# 22. قاعدة الحوار

كل حوار يجب أن يملك نافذة زمنية واضحة.

مثال:

```text
5.5–7.5 seconds:
The character speaks exactly one short sentence in natural Algerian Darija.

Begin speaking around 5.5 seconds.
Finish the complete sentence before 7.5 seconds.

Do not postpone the dialogue until the final seconds.
Do not add words.
Do not translate the dialogue.
```

الهدف:
- دارجة جزائرية طبيعية.
- لا فصحى.
- لا نبرة مذيع.
- لا نبرة تعليمية.
- لا كلام طويل في 10 ثواني.

---

# 23. قاعدة الاستمرارية

نهاية فيديو = بداية الفيديو التالي.

الصورة المرجعية تثبت الشكل.
الـPrompt يحدد الحركة.

لا تجعل كل فيديو يخترع شخصية جديدة.

---

# 24. معيار قبول الصورة

الصورة تُقبل إذا:
- تبدو Live-Action.
- الشخصية بشرية وواقعية.
- الشخصية أصلية وخيالية.
- لا تشبه شخصًا معروفًا.
- الوجه ثابت بين الصور.
- الملابس ثابتة عندما يجب.
- الإضاءة والمكان مناسبين.
- اليدان والوجه بلا تشوه.
- لا توجد شخصيات مكررة.
- لا يوجد نص أو Watermark أو Logo غير مطلوب.

---

# 25. التعليمات النهائية للوكيل

لا تعيد توليد كل الصور عشوائيًا.

أولًا أنشئ Character References.
ثم قارن الصور الحالية بها.
أعد فقط الصور التي تحتاج إلى توحيد.
حافظ على أسماء الملفات الأصلية.
حافظ على ترتيب المشاهد والأحداث.
لا تغيّر القصة.
لا تغيّر صور سوبر ذزيري المقنّع الجيدة.
لا تبدأ إنتاج الفيديو قبل انتهاء مرحلة توحيد الشخصيات.

**الهدف النهائي:**
كل المشاهد يجب أن تبدو كأنها صُورت في نفس الفيلم، بنفس الشخصيات، بنفس العالم، وبنفس التصميم السينمائي.
